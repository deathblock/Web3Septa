# Web3Septa

Enables automated backups of MySQL databases to Amazon S3 storage for small to medium-sized businesses.

Web3Septa is built to be simple and practical, focusing on doing one thing well.

**Why Web3Septa?**

- Enables automated backups of MySQL
- databases to Amazon S3 storage
- for small to medium-sized businesses

## Key Features

- Enables automated backups of MySQL
- databases to Amazon S3 storage
- for small to medium-sized businesses

## Technology Stack

- typescript
- typescript framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/Web3Septa.git`
2. `cd Web3Septa`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure Web3Septa, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
